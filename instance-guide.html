인스턴스 생성 가이드

오픈스택 스카이라인 대시보드를 통한 VM 인스턴스 생성 단계

STEP 1. 대시보드 로그인

메인 화면의 [Start] 버튼을 눌러 스카이라인 대시보드에 접근한 뒤, 발급받은 계정으로 로그인합니다.

STEP 2. 인스턴스 메뉴 이동

좌측 네비게이션 메뉴에서 [컴퓨팅] ➔ [인스턴스]를 선택한 후 우측 상단의 [인스턴스 생성] 버튼을 클릭합니다.

STEP 3. 소스 및 사양(Flavor) 선택

인스턴스의 운영체제 이미지(예: Ubuntu 22.04)를 할당하고, 팀 프로젝트 요구 사양에 맞는 사양(Flavor)을 선택합니다.

STEP 4. 네트워크 및 키페어 설정

할당받은 네트워크 프라이빗 서브넷을 지정하고, 원격 접속 시 필수적인 보안 비밀키(Keypair)를 등록하거나 새로 생성합니다.
