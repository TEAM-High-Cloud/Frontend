SSH 접속 가이드

인스턴스 생성 시 등록한 키페어 파일(.pem)을 이용하여 가상 서버에 원격 접속하는 방법입니다.

Xshell을 통한 세션 연결
  1. Xshell 프로그램을 실행한 뒤 좌측 상단의 [새로 만들기]를 클릭합니다.
  2. 호스트 주소 칸에 인스턴스의 Floating IP(공인 IP)를 입력합니다.
  3. 좌측 메뉴에서 [사용자 인증]을 누르고, 방법을 [Public Key]로 변경합니다.
  4. 사용자 이름에 ubuntu를 입력한 뒤, 다운로드받은 키페어 파일(.pem)을 불러옵니다.
  5. 연결을 누르고 보안 경고창이 뜨면 수락 후 원격 접속을 시작합니다.
Linux / macOS / PowerShell CLI 접속
# 1. 키페어 파일 권한 축소 (최초 1회 필수)
chmod 400 your-key.pem

# 2. SSH 접속 명령 실행
ssh -i your-key.pem ubuntu@[인스턴스_IP 주소]
  1. 다운로드받은 키페어 파일이 위치한 폴더에서 터미널 창을 실행합니다.
  2. 키페어 보안 권한이 너무 열려있으면 리눅스가 거부하므로 위의 chmod 400 명령어로 관리자 전용 읽기 권한만 부여합니다.
  3. ssh 인라인 접속 구문을 이용하여 원격 인프라 서버에 직통 연동합니다.
